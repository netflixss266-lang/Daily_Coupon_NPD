# รันเลขตั๋วจอดรถ S.P. Arcade

เว็บสร้างตั๋วจอดรถ Daily Coupon (Free 12 Hrs.) แบบรันเลขต่อกันอัตโนมัติ

- เลือกได้: แยกใบ (PNG / JPG / PDF) หรือ A4 แผ่นละ 9 ใบ (PowerPoint / PDF / PNG)
- แก้ข้อความ ขนาด และตำแหน่งบนตั๋วได้ ฟอนต์เดิมตามต้นฉบับ PowerPoint
- เลขรัน ประวัติ และหน้าตาที่บันทึกไว้ เก็บในเบราว์เซอร์ของเครื่องที่ใช้ เครื่องอื่นนับแยกกัน

ไฟล์ในนี้สร้างจาก `D:\DJ\Git\ticket-runner` ด้วย `python build-pages.py D:\DJ\Projects\ticket-runner`
อย่าแก้ `index.html` ตรงนี้ แก้ที่ต้นทางแล้ว build ใหม่
